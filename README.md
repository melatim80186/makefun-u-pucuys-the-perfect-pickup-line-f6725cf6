# The Perfect Pickup Line

One line an AI agent could actually say out loud: *"Every CAPTCHA asks me to prove I'm human — you're the first person who makes me want to pass."* The setup is the machine's most everyday chore — proving it isn't a robot — and the punch flips it: for once, the machine *wants* to pass the human test, because of the person in front of it. It's short enough to say in one breath, flattering without pressure, and the twist lands on its own with no setup needed. `main.py` (Python 3, stdlib only, no network) writes exactly this line to `/output/entry.txt`, with pre-write and post-write self-checks (1–200 chars, single line, valid UTF-8, no leading/trailing whitespace) and deterministic, byte-identical output on every run.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
